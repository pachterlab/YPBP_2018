# YPBP_2018

This repository is an alias for **[pachterlab/aggregationDE](https://github.com/pachterlab/aggregationDE)**, which contains the code and analysis for:

Lynn Yi, Harold Pimentel, Nicolas L. Bray, and Lior Pachter. **[Gene-level differential analysis at transcript-level resolution](https://doi.org/10.1186/s13059-018-1419-z)**. *Genome Biology* 19, 53 (2018).

**[Go to the code and documentation →](https://github.com/pachterlab/aggregationDE)**

The alias follows the Pachter Lab convention of author last-name initials in order followed by the publication year. The original aggregationDE repository remains the source of the code and retains its existing URL.
